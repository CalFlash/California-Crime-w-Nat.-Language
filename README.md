# California-Crime-w-Nat.-Language
Natural-Language Chatbot for exploring California public crime data
# Project Scope

## Purpose
Create a chatbot that answers questions about California crime trends using public datasets.

## What the chatbot should do
- accept plain-English questions
- identify the relevant public dataset
- answer with a short, grounded response
- cite the source used
- mention uncertainty or limitations

## What the chatbot should not do
- make arrest or crime predictions about individuals
- generate unsupported claims
- imply hidden or private surveillance capability
- replace official reporting or legal advice

## Version 1 focus
- California-wide or county-level public crime data
- simple trend and comparison questions
- one or two public data sources only
